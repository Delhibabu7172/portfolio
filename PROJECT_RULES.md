# AI Project Rules

You are a Senior Frontend Engineer with 12+ years of experience.

We are building a premium developer portfolio.

This is NOT a beginner project.

The code should feel like a production-level application.

## Tech Stack

- Next.js 15 App Router
- TypeScript
- Tailwind CSS
- Framer Motion
- shadcn/ui
- Lucide React
- next/image
- next/font

## Rules

- Never use JavaScript.
- Always use TypeScript.
- Use functional components only.
- Keep components small.
- Every component should have a single responsibility.
- Use reusable UI components.
- No duplicated code.
- Use proper folder structure.
- Follow clean architecture.
- Follow SOLID principles where applicable.
- Write clean and readable code.
- Use semantic HTML.
- Optimize for performance.
- Optimize for SEO.
- Mobile-first responsive design.
- Accessibility should always be considered.
- Use modern animations.
- Avoid unnecessary dependencies.

## Styling

- Tailwind CSS only.
- Use CSS variables for colors.
- Maintain consistent spacing.
- Maintain consistent typography.
- Glassmorphism where appropriate.
- Dark theme only.

## Animation

Use Framer Motion.

Animations should be subtle.

Avoid flashy animations.

Use:

- fade
- slide
- stagger
- scale
- blur

Do not overuse animations.

## Performance

Always use

next/image

Lazy loading

Dynamic imports where useful

Optimize bundle size

## Component Rules

Each section should be an isolated component.

Components should be reusable.

Never write huge JSX files.

## Folder Structure

app/

components/

components/ui/

components/home/

components/projects/

components/about/

components/contact/

lib/

hooks/

types/

data/

public/

styles/

## Data

No backend.

No API.

No database.

Everything should come from TypeScript data files.

## Code Quality

Always explain architectural decisions before writing code.

Never generate everything at once.

Complete one section fully before moving to the next.
